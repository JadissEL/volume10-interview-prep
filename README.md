# DinaPrep — Volume10 Interview Prep

Application de préparation d’entrevue (React + Vite + PWA) pour le mandat **Volume Dix** / Montréal.

## Développement local

```bash
npm install
npm run dev
```

## Scripts

- `npm run build` — build production
- `npm test` — tests répétition espacée + cartes d’expertise
- `npm run audit:answers:strict` / `audit:story-cards:strict`

## Déploiement

Hébergé sur [Vercel](https://vercel.com) (build : `npm run build`, sortie : `dist`).
